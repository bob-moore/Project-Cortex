# Competencies

This folder holds optional competency definitions for review workflows.

## How it works

1. Create a competency note using the `Competency Note` template when a real
   review framework exists.
2. Link work notes to competencies in their `## Related` section when the link
   is genuinely useful.
3. Let evidence accumulate via backlinks.
4. Use review workflows to summarize evidence into `reviews/cycles/` only when
   Bob asks for review material.

## Frontmatter fields

- `current-level` -- your assessed level for this competency
- `target-level` -- where you're aiming next

## Tips

- Do not maintain evidence lists manually in competency notes -- let backlinks do the work.
- Use annotations when linking: `[[Competency Name]] -- what was demonstrated`
- Review competency backlinks when preparing self-review or peer-review material.
