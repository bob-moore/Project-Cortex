# Reviews

This folder is for optional review material: self-reviews, peer reviews, impact
summaries, candidate evidence, competency mapping, and review cycles.

Mid-West Family Madison does not currently run a formal performance-review
process. Do not prompt Bob to backfill this folder or treat empty review areas
as a gap. Use it when Bob explicitly asks for review prep, a self-review,
resume/career evidence, a summary of accomplishments, or a peer-review packet.

| Cycle | Status | Notes |
|---|---|---|
| [[2026-Q3]] | Raw candidate evidence | Day-to-day work capture from the previous system; not curated review evidence yet. |

## Folders

- `cycles/` — review-cycle notes and generated review drafts.
- `evidence/` — saved source packets, PR scans, Slack scans, or other review evidence.
- `competencies/` — optional competency definitions if a review framework is created.

## Method

Review workflows should mine existing work records first:

- `Projects/active/` and archived project notes
- `Clients/` and client-specific project artifacts
- `Notes/meetings/`, `Notes/1-1/`, and `Notes/incidents/`
- commits, PRs, Slack, calendar, and other external systems when explicitly in scope

Only write to `reviews/` when the user asks for review material or approves
capturing a specific piece of evidence.
