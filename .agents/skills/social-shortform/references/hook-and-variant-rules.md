# Hook And Variant Rules

Use this reference for short-form social generation.

## Hook Types

- Contrarian: challenge a common belief.
- Practical: promise a specific useful takeaway.
- Story: start with a concrete moment.
- Data: use a verified statistic.
- Question: ask what the audience is already wondering.
- Mistake: name a common error.

## Variant Discipline

Variants should test meaningful differences:

- Angle.
- Audience.
- CTA.
- Formality.
- Hook type.
- Length.

Do not produce five near-duplicates.

## Claim Compression

When shortening a claim:

- Preserve scope.
- Preserve caveats.
- Keep attribution when needed.
- Avoid turning qualitative claims into quantitative claims.
- Avoid making one example sound universal.

## Hashtags And Emojis

Use only when platform, brand, or prompt supports them. Do not add decorative
formatting by default.
