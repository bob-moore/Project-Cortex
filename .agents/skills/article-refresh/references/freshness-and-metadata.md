# Freshness And Metadata

Use this reference when refreshing long-form content.

## Date Rules

Keep original publish date unchanged.

Update `lastUpdated` or equivalent only when the refresh changes:

- Facts.
- Recommendations.
- Methods.
- Product details.
- Pricing.
- Source evidence.
- Material copy.

Do not update freshness metadata for grammar-only edits.

## Metadata

Check:

- Title tag still matches visible content.
- Meta description is accurate and specific.
- Slug still fits the topic.
- Cover image and alt text remain accurate.
- Tags or categories still fit.

## Staleness Signals

Flag:

- Old year in title or heading.
- Expired offer.
- Outdated platform feature.
- Broken link.
- Current claim without current source.
- Screenshot or image that no longer reflects the product.
