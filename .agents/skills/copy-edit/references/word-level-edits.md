# Word Level Edits

Use this reference for final polish after structure, intent, and voice are
stable.

## Cut Filler

Remove when meaning survives:

- very
- really
- just
- actually
- basically
- literally
- quite
- rather
- somewhat
- in order to
- due to the fact that
- for the purpose of

## Replace Weak Or Inflated Terms

| Instead Of | Prefer |
| --- | --- |
| utilize | use |
| leverage | use, draw on, apply |
| facilitate | help, make possible |
| implement | build, add, use, launch |
| robust | specific strength |
| seamless | specific ease or connection |
| innovative | specific difference |
| comprehensive | what is included |
| optimize | improve a named metric or behavior |
| empower | let, help, give |

## Sentence Checks

- Keep one main idea per sentence.
- Put the actor near the action.
- Prefer active voice when the actor is known.
- Split sentences that bury the point after multiple clauses.
- Preserve longer sentences when they carry useful rhythm and remain clear.

## Paragraph Checks

- Use short paragraphs for web, email, and social.
- Use headings or bullets when readers need to scan.
- Keep article paragraphs longer only when explanation benefits.
- Start paragraphs with the point, not throat-clearing.

## Punctuation And Formatting

- Remove overused bolding.
- Use title case only when the destination style expects it.
- Avoid decorative formatting.
- Replace repeated em-dash structures when they create a generic rhythm.
- Keep markdown valid when editing Obsidian notes.

## Final Comparison

Before delivery, compare the edited draft to the source:

- Meaning preserved.
- Facts preserved.
- Voice improved.
- Constraints followed.
- Open claims flagged.
- No new unsupported detail introduced.
