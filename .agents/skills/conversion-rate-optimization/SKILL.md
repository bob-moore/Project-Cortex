# Conversion Rate Optimization

Use this skill to diagnose why a marketing page or form is not converting and
produce prioritized recommendations or test hypotheses.

## Operating Contract

1. Resolve page/form, conversion goal, traffic source, visitor intent, current
   metric, target metric, and evidence available.
2. Use analytics, heatmaps, recordings, research, sales objections, support
   tickets, screenshots, rendered inspection, and copy review when available.
3. Separate diagnosis from implementation.
4. Route copy to Writer, visual changes to Designer, code to Developer,
   WordPress state to WordPress Operator, and tracking issues to Analytics.
5. Do not claim a conversion lift without measured evidence.

## Analysis Order

1. Value proposition clarity.
2. Message match to channel, search intent, referral, or campaign promise.
3. CTA hierarchy and action clarity.
4. Proof, trust, and risk reversal.
5. Objection handling.
6. Form friction and mobile usability.
7. Scannability, accessibility, and visual hierarchy.
8. Measurement integrity.
