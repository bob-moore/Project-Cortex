# Preservation Check

Use this check after rewriting and before delivery.

## Compare Against Source

Check each category.

```text
Facts:
Names:
Dates:
Numbers:
Quotes:
Claims:
CTA:
Audience:
Offer:
Tone:
Format:
Required terms:
Forbidden terms:
```

## Red Flags

Flag and correct:

- New statistic added without evidence.
- Claim strengthened beyond the source.
- Caveat removed from a high-stakes statement.
- Quote altered without instruction.
- Product, company, or person renamed.
- CTA changed to a different commitment.
- Voice shifted away from the provided voice source.
- Formatting changed in a way that breaks the destination.

## Change Note

Use this compact note when useful:

```text
Preserved:
- ...

Changed:
- ...

Flagged:
- ...
```

## Authorship Boundary

Do not say a piece "was written by AI" or "passes AI detection" based on prose
patterns. Say what changed in reader-facing editorial terms:

```text
Changed repeated formulaic transitions and inflated phrasing so the draft reads
more direct and specific.
```
