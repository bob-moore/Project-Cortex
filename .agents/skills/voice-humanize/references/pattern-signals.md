# Pattern Signals

Use this reference to identify prose patterns worth revising. Treat these as
editorial signals, not proof of authorship.

## Counting Rule

Most signals matter when they cluster.

- Count repeated terms or structures before flagging overuse.
- Ignore isolated normal usage when it fits the voice.
- Consolidate several signals in one sentence into one finding.
- Under-flag when uncertain.

## Inflated Significance

Signals:

- serves as
- stands as
- testament
- pivotal
- underscores
- broader trend
- evolving landscape
- lasting impact

Fix by stating the concrete fact and why it matters.

## Promotional Filler

Signals:

- powerful
- seamless
- robust
- innovative
- cutting-edge
- game-changing
- must-have
- commitment to excellence

Fix with specific evidence, a concrete feature, or deletion.

## Fake Depth

Signals:

- highlighting
- underscoring
- reflecting
- encompassing
- fostering
- ensuring
- symbolizing

Fix by splitting the sentence, naming the actual relationship, or deleting the
false analysis.

## Formulaic Structure

Signals:

- Repeated "not only X but also Y".
- Repeated "from X to Y" ranges without a real scale.
- Back-to-back groups of three where the third item pads the list.
- Repeated question headings across a long-form draft.
- Generic wrap-up questions.
- Symmetric list items with nearly identical shape despite unequal substance.

Flag only when the structure repeats or weakens the piece.

## Repetitive Rhythm

Signals:

- Three-clause sentence rhythm repeated across a section.
- Multiple paragraphs opening with the same word or phrase.
- Several consecutive sentences with similar length.
- More than two hedges in a short span.

Fix by varying sentence length, moving the main point earlier, or cutting
unneeded scaffolding.

## Chat Residue

Remove:

- Great question.
- Hope this helps.
- Let's dive in.
- Here is an overview.
- As an AI language model.
- Let me know if...

These belong to chat, not finished copy.

## Over-Styled Formatting

Signals:

- Excessive bolding.
- Decorative emoji.
- Inline-header bullets in every list.
- Repeated dramatic punctuation.
- Title case where the house style uses sentence case.

Fix only when formatting distracts from the artifact or conflicts with the
destination style.
