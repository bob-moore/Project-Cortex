# Voice Calibration

Use this reference before rewriting when the target voice is unclear, mixed, or
client-specific.

## Voice Source Priority

Use the most specific reliable source.

1. Direct instruction in the current conversation.
2. Client Voice note.
3. Client Brand note.
4. Approved examples in the vault.
5. User-provided sample.
6. The draft's strongest natural passages.
7. Judged editorial voice.

When sources conflict, follow the current direct instruction unless it would
violate a known approval boundary, factual constraint, or compliance need.

## Calibration Fields

Capture only what affects the rewrite.

```text

```

## Voice Fit Rules

- Match the source voice, not a generic idea of "human".
- Preserve technical language when it is the clearest term for the audience.
- Preserve local or domain-specific phrasing when it is intentional.
- Keep restraint when the brand is serious, professional, or regulated.
- Use contractions only when the voice source supports them.
- Use first person only when the format, operator, or brand voice allows it.

## Provisional Voice

When no voice source exists, mark voice work as judged.

```text
Voice assumption: judged editorial voice, direct and plain, because no Brand or
Voice note was available.
```

Do not represent judged voice as client-approved voice.
