# Verification Process

Use this reference when checking sources.

## Source Inspection

Inspect the source for:

- Same entity.
- Same value.
- Same timeframe or study period.
- Same audience, market, or geography.
- Same direction of comparison.
- Same caveats or limitations.

A source can mention the same number and still fail if the context differs.

## Risk Levels

| Risk | Use When |
| --- | --- |
| low | editorial or low-impact claim; little harm if softened |
| medium | commercial claim, capability claim, or trust claim needing support |
| high | public statistic, comparison, outcome claim, testimonial, guarantee, or named authority |
| critical | high-stakes legal, medical, financial, employment, compliance, safety, regulated, or platform-policy claim |

## Actions

Use one of:

- `keep`: support is adequate.
- `keep-with-caveat`: support exists but scope must be stated.
- `source`: claim may be usable but needs support.
- `soften`: reduce certainty, specificity, or scope.
- `replace`: use a supported alternative.
- `remove`: claim should not remain.
- `ask`: operator input is needed.

## Source Access Boundaries

If external access is unavailable or not approved, do not imply live
verification. Mark status as `unverified` and state what source would be needed.

When access is available, inspect a reasonable number of sources per pass and
list any skipped sources separately.
