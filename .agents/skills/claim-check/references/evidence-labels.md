# Evidence Labels

Use consistent labels across writing skills.

## source-backed

Use when a claim is supported by an inspected citation, linked source, source
document, or authoritative reference.

Record:

- Source title or name.
- URL or vault path.
- Date or study period when relevant.
- Retrieval date for changeable web sources.
- Any scope limitation.

## user-provided

Use when the operator, client notes, brand docs, briefs, or project docs supply
the claim.

This label means provenance is known. It does not automatically prove public
truth. Public-facing high-risk claims may still need source-backed evidence.

## measured

Use when the claim comes from inspected data, analytics, tooling output, or
artifact counts.

Record the measurement method.

## judged

Use for editorial assessments that do not need factual verification.

Examples:

- "The paragraph is hard to scan."
- "The CTA is buried."

## assumed

Use when the claim is necessary for the draft but unsupported.

Assumed claims should usually become open items. Do not present assumed claims as
verified.
