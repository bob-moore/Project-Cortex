# Article Types

Use the article type to shape the brief.

| Type | Use For | Evidence Emphasis |
| --- | --- | --- |
| how-to-guide | step-by-step instruction | process accuracy, screenshots, examples |
| explainer | understanding a topic | definitions, examples, source-backed context |
| comparison | choosing between options | criteria, tradeoffs, current details |
| case-study | specific result or project | first-hand evidence, metrics, quotes |
| thought-leadership | perspective or argument | clear thesis, reasoning, selective support |
| news-analysis | timely development | current sources and date clarity |
| product-review | evaluation | tested evidence, criteria, limitations |
| listicle | curated options | selection criteria and current details |
| faq-knowledge | question-led reference | concise answers, source-backed facts |
| data-research | data or survey analysis | methodology, sample, limitations |

Choose the type that matches reader need, not the legacy blog template list.
