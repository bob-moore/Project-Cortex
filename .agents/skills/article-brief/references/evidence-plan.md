# Evidence Plan

Use this reference to plan evidence before outlining or drafting.

## Evidence Sources

Possible sources:

- User-provided notes.
- Client docs.
- Project evidence.
- Interviews.
- Analytics or measurements.
- Public sources.
- Product docs.
- Case studies.
- Original data.

## Evidence Table

Use:

```text
| Claim Need | Evidence Type | Source Status | Risk | Draft Rule |
| --- | --- | --- | --- | --- |
| ... | source-backed | needed | high | do not state until sourced |
```

## Draft Rules

- Use source-backed support for public statistics and high-risk claims.
- Use user-provided support for internal/client context, with caveats when public
  verification is still needed.
- Use judged support only for editorial analysis.
- Mark unsupported claims as assumptions or open questions.
- Drop statistics that cannot be verified.
