# Page Handoff

Use this reference when returning copy for a designer, developer, site operator,
or implementation workflow.

## Section Shape

Return page copy in implementation-friendly sections:

```text
Page:
Web intent:
Audience:
Primary CTA:

Hero
- Eyebrow:
- H1:
- Subhead:
- CTA:
- Proof note:

Section
- Purpose:
- Heading:
- Body:
- CTA:
- Evidence:
```

Keep labels functional. Do not over-prescribe layout unless asked.

## Metadata

Include when requested or useful:

```text
Title tag:
Meta description:
Suggested slug:
Open graph title:
Open graph description:
```

Metadata should be clear and truthful. SEO keywords belong naturally; keyword
stuffing fails the writing gate.

## Evidence Notes

For each material claim, label evidence:

- `source-backed`
- `user-provided`
- `measured`
- `judged`
- `assumed`

Example:

```text
Claim: Same-day estimate available.
Evidence: user-provided.
```

## Open Items

List unresolved items clearly:

- Missing proof.
- Placeholder testimonial.
- Unconfirmed offer detail.
- Unconfirmed pricing.
- Missing brand voice source.
- SEO keyword not provided.
- Need legal or compliance review.

Do not hide open items inside polished copy.
