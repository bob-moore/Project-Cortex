# Web Intents

Use this reference to decide how persuasive a web page should be.

## Standard Intent

Standard web copy helps readers understand, trust, and navigate.

Common pages:

- Homepage.
- About page.
- Service page.
- Product information page.
- Team page.
- Contact page.
- Location page.
- FAQ page.
- Resource landing page.

Standard pages can still persuade. They should usually persuade through clarity,
fit, credibility, and usefulness rather than pressure.

Good standard copy:

- Explains what the page is about quickly.
- Names the right audience.
- Shows relevant proof without overplaying it.
- Uses simple CTAs.
- Keeps the tone calm unless the brand says otherwise.

Avoid:

- Fake urgency.
- Aggressive scarcity.
- Overloaded offer stacks.
- Long objection sections when the reader mainly needs orientation.
- Superlatives without proof.

## Promotional Intent

Promotional web copy is built around a conversion event.

Common pages:

- Landing page.
- Sales page.
- Campaign page.
- Offer page.
- Webinar or event registration page.
- Lead magnet page.
- Paid traffic destination.
- Product launch page.

Promotional pages may use direct persuasion, stronger CTAs, offer framing,
urgency, objection handling, and repeated conversion moments.

Good promotional copy:

- Names the audience and buying moment.
- States the promise plainly.
- Explains the mechanism.
- Shows proof.
- Handles objections.
- Makes action easy.
- Uses urgency only when real.

Avoid:

- Unsupported outcome claims.
- Invented testimonials.
- Fake limited availability.
- Manipulative fear.
- Pressure that conflicts with brand trust.

## Hype Versus Persuasion

Persuasion helps the reader make a decision.

Hype asks for belief without evidence.

| Allowed In Promotional Copy | Not Allowed |
| --- | --- |
| clear promise | vague superiority |
| direct CTA | pressure without context |
| real urgency | fake scarcity |
| proof-backed result | invented metric |
| objection handling | dismissing concerns |
| contrast with alternatives | unsupported attack |

When asked to avoid sales hype on a promotional page, write sales copy with
specific proof, plain language, and honest urgency.
