# SEO Hreflang

Execute `seo-hreflang` and run:

`python3 .agents/tools/seo/gap-check.py --mode hreflang --target <path-or-url>`

Preserve observed codes, duplicates, missing href values, and the limitation
that one page cannot prove reciprocal coverage or locale intent. Apply
`seo-quality-gate` and hand routing changes to the developer or WordPress
operator.
