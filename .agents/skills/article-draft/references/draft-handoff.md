# Draft Handoff

Use this reference when delivering a complete article draft.

## Handoff Fields

```text
Mode:
Article type:
Audience:
Search goal:
Evidence labels:
Open claims:
Missing assets:
Internal link needs:
Recommended next pass:
```

## Recommended Next Pass

Choose one or more:

- `claim-check`: when factual claims need extraction or verification.
- `copy-edit`: when the draft needs clarity, structure, grammar, and voice.
- `voice-humanize`: when prose feels generic or model-shaped.
- `writing-quality-gate`: when readiness needs a verdict.

## File Writes

Write to the vault only when the workflow allows `vault_write` and the target
path is clear. Otherwise return the draft inline.
