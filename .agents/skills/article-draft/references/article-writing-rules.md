# Article Writing Rules

Use these rules while drafting.

## Introduction

The introduction should:

- Orient the reader.
- Name the problem, question, or decision.
- State the article promise.
- Avoid generic throat-clearing.
- Avoid unsupported statistics as a hook.

## Sections

Each H2 should:

- Answer a real reader question.
- Start with the main point or useful context.
- Include evidence where the claim needs it.
- Use examples, tables, or bullets when they help.
- End by moving the reader forward.

## Summary Elements

Use key takeaways or TLDR blocks only when they help the reader. Keep them
self-contained and free of unsupported claims.

## Conclusion

The conclusion should:

- Summarize the useful answer.
- Reinforce the next step.
- Avoid adding new claims.
- Avoid generic closing filler.

## Style

- Follow Brand and Voice notes.
- Use clear headings.
- Keep paragraphs sized to the audience and channel.
- Prefer concrete language.
- Keep technical language when the audience needs precision.
