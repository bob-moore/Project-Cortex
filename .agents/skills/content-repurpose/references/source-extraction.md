# Source Extraction

Use this reference to extract reusable material from a source artifact.

## Extract

- Title.
- Source type.
- Audience.
- Thesis.
- Key ideas.
- Examples.
- Quotes.
- Statistics.
- Claims.
- Proof.
- Caveats.
- CTA.
- Voice.

## Evidence Status

Label each reusable claim:

- source-backed.
- user-provided.
- measured.
- judged.
- assumed.

Do not reuse unsupported statistics as facts.

## Source Map

Use:

```text
| Source Element | Evidence | Safe Uses | Unsafe Uses |
| --- | --- | --- | --- |
```

The source map keeps derivative outputs traceable.
