# Target Routing

Use this reference to route derivative outputs.

## Targets

| Target | Skill | Notes |
| --- | --- | --- |
| newsletter issue | email-newsletter | editorial or curated format |
| promotional email | email-newsletter | use promotional-email intent |
| nurture sequence | email-newsletter | one idea per email |
| LinkedIn post | social-shortform | professional insight |
| X thread | social-shortform | numbered, one idea per post |
| caption | social-shortform | visual-adjacent |
| shorts script | social-shortform | hook and beats |
| CTA block | web-copy | page or landing-page adaptation |
| article brief | article-brief | planning from source |
| article outline | article-outline | structure from source |

## Routing Rule

Repurpose extracts and maps. Target skills shape final copy.

When generating a bundle directly, apply each target skill's core contract
inside the output notes.
