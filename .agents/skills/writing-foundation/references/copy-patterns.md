# Copy Patterns

Use these patterns as structures, not formulas to force onto every artifact.

## Problem Agitate Solve

Use when the reader already feels the problem and needs urgency.

```text
Problem: Name the pain in recognizable language.
Agitate: Show the cost of leaving it unresolved.
Solve: Present the offer, idea, or action as the path out.
```

Avoid exaggerated agitation. Keep the cost truthful.

## AIDA

Use for ads, emails, sales sections, and conversion-focused flows.

```text
Attention: earn the next second.
Interest: make the problem or opportunity relevant.
Desire: connect the solution to the wanted outcome.
Action: ask for one clear next step.
```

## Before After Bridge

Use for transformation stories.

```text
Before: current state.
After: better state.
Bridge: mechanism that connects them.
```

Keep the "after" grounded in available proof.

## Feature Benefit Translation

Use when source material is feature-heavy.

```text
Feature:
Which means:
So the reader can:
Proof:
```

Example:

```text
Feature: Real-time sync.
Which means: Updates appear across devices without manual refreshes.
So the reader can: pick up work where it left off.
Proof: product behavior, demo, or documentation required.
```

## Objection Answer

Use when hesitation is the barrier.

```text
Concern:
Truthful answer:
Proof:
Risk reversal or next step:
```

Do not answer objections with unsupported guarantees.

## CTA Patterns

Make calls to action specific and low-friction.

Prefer:

- Start the assessment.
- Get the estimate.
- See available times.
- Compare options.
- Send the brief.

Avoid:

- Submit.
- Click here.
- Learn more, unless the action truly is informational.

## Page Sequence

For web-copy mode, a common sequence is:

1. Hero: promise, audience, action, proof.
2. Problem: recognizable pain.
3. Outcome: better state.
4. Mechanism: how it works.
5. Proof: examples, testimonials, data, credentials.
6. Objections: risks, timing, pricing, switching cost.
7. Action: repeat the primary CTA.

Adjust the sequence to the actual mode. Do not require a full page structure for
short email, social, or review artifacts.
