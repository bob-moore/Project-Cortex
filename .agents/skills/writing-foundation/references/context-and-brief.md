# Context And Brief

Use this reference when the prompt does not already provide a complete writing
contract.

## Minimum Viable Brief

Capture only the fields needed to draft responsibly.

```text
Client/project:
Artifact type:
Mode:
Audience:
Audience awareness:
Reader problem or desire:
Desired action:
Primary promise:
Proof available:
Offer or subject details:
Voice constraints:
Forbidden claims or terms:
Deadline or channel constraints:
Approval boundary:
Open assumptions:
```

## Context Priority

Use the most specific context available.

1. Direct user instruction in the current conversation.
2. Client, project, campaign, or brief notes in the vault.
3. Brand and voice notes.
4. Prior decisions, examples, or approved artifacts.
5. General discipline guidance.

When sources conflict, prefer the more recent and more specific instruction.
Surface the conflict when it affects the artifact.

## Missing Context Handling

Ask for missing context when the missing field changes strategy, risk, or
approval boundaries.

Proceed provisionally when the task is low risk and the missing field can be
labeled as an assumption. Mark provisional copy clearly.

Examples of blocking missing context:

- Client-specific brand or voice work without any brand/voice source.
- Regulated claims without evidence or required disclaimers.
- Testimonial, case study, result, or statistic requests without proof.
- External publishing, sending, scheduling, or platform mutation without
  approval.

Examples of acceptable assumptions:

- Drafting rough headline directions before final audience selection.
- Creating placeholder CTA options for review.
- Producing a first-pass rewrite with tone assumptions stated.

## Approval Classes

Respect the approval class from the workflow or discipline contract.

- `read_only`: inspect and summarize only.
- `vault_write`: create or edit vault artifacts.
- `external_read`: read outside systems when approved and available.
- `external_mutation`: publish, send, schedule, update, or otherwise mutate an
  external system only after explicit approval.
