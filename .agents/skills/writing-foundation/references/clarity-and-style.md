# Clarity And Style

Use this reference for revision, cleanup, and final polish.

## Clarity Checks

Run these checks before treating copy as ready.

- First line names a problem, outcome, decision, or useful subject.
- Each paragraph contains one idea.
- Long sentences are split when they slow comprehension.
- Abstract nouns are replaced with concrete nouns where possible.
- Features connect to benefits.
- Claims are specific enough to verify.
- The next action is clear.
- Tone follows available Brand and Voice context.

## Common Failures

| Failure | Symptom | Correction |
| --- | --- | --- |
| Feature dump | specs without reader value | translate each feature into an outcome |
| Company-first copy | starts with "we" or history | start with the reader's situation |
| Clever over clear | memorable but unclear phrasing | state the plain message first |
| Jargon | insider words or inflated claims | use the words a buyer would use |
| Vague promise | "grow faster" or "save time" | name the result, audience, or mechanism |
| Buried action | CTA appears late or vaguely | place one direct action near the decision point |
| Unsupported proof | metrics or testimonials without source | remove, label, or request evidence |

## Plain Language

Prefer direct replacements when meaning is unchanged.

| Instead Of | Use |
| --- | --- |
| utilize | use |
| facilitate | help |
| leverage | use |
| robust | strong, reliable, or specific feature |
| seamless | easy, connected, or specific behavior |
| best-in-class | specific proof or delete |
| innovative | new, different, or specific mechanism |
| due to the fact that | because |
| in order to | to |

## Rhythm

Vary sentence length intentionally. Use short sentences for key points. Use
longer sentences only when the relationship between ideas matters.

For web copy, favor scanability:

- Short paragraphs.
- Useful subheads.
- Bullets for lists.
- Front-loaded key terms.

For editorial or article copy, allow more rhythm and explanation, but keep the
reader's path clear.

## Final Pass

Before handoff, remove:

- Empty intensifiers: very, really, extremely, totally.
- Unsupported superlatives.
- Duplicate claims.
- Topic drift.
- Placeholder proof.
- Tone that conflicts with the project voice.

When a phrase sounds polished but vague, rewrite it as a concrete promise,
mechanism, or reader action.
