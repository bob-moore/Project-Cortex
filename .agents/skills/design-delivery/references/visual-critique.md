# Visual Critique

Use the applicable lenses for redesign and rendered implementation review.
Each finding should include observation, problem, fix, severity, evidence, and
owner.

## Lenses

### Affordance

Check whether interactive elements look interactive, states are visible, the
primary action is obvious, hover-only controls have touch alternatives, disabled
states do not rely on color alone, and focus is visible.

### Brand Consistency

Compare against actual client Brand, Voice, and Design Tokens. If those files
are missing or placeholder-only, mark the gap instead of inventing brand rules.

### Color

Check contrast, token use, semantic color consistency, non-color indicators,
and forced-colors/high-contrast implications where relevant.

### Composition

Check balance, whitespace, rhythm, proximity, similarity, figure/ground,
alignment, continuity, and whether the layout has a clear center of gravity.

### Information Density

Check cognitive load, content priority, scanning pattern, progressive
disclosure, and whether the surface serves one clear primary task.

### Typography

Check scale, readability, line-height, line length, hierarchy, consistency, and
token compliance.

### Visual Hierarchy

Check entry point, eye flow, emphasis, weight, CTA prominence, and whether the
highest-emphasis element matches the user's real task.

## Finding Shape

```text
Lens:
Observation:
Problem:
Fix:
Severity:
Evidence:
Owner:
```
