# Disciplines

Disciplines group related skills, workflows, modes, rubrics, and migration
decisions across a work domain.

A discipline is not a role. A discipline tells the harness how a domain is
organized; roles perform bounded work, workflows define tasks, and skills
provide reusable procedures or references.

Current canonical disciplines:

- `accessibility`
- `design`
- `development`
- `marketing`
- `seo`
- `wordpress-operations`
- `writing`

Validate with:

```bash
node .agents/scripts/verify-disciplines.mjs
```
