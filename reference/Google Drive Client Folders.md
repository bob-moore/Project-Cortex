# Google Drive Client Folders

Every client has a named folder in Google Drive, nested under one of three alphabetical sub-folders inside the shared parent:

**Parent folder:** [Client Folders](https://drive.google.com/drive/folders/1ajfErhVmWfyjewc1tXzzOL2YNbCSa7g1?usp=drive_link)

- **A-H** — client names starting A through H
- **I-P** — client names starting I through P
- **Q-Z** — client names starting Q through Z

A client's folder inside the correct sub-folder is where the full context lives — contracts, meeting notes, brand guidelines, old copy decks, questionnaires, whatever the account team has gathered. Drive is the source-of-record for raw client documents; the vault's `<Client> Brand.md` and `<Client> Voice.md` are the distilled, agent-usable output.

## How to use this

1. Find the client's first letter, pick the matching sub-folder (A-H / I-P / Q-Z).
2. Search that sub-folder for a folder named after the client with the available Google Drive connector/tool, scoped to the sub-folder if the tool supports a parent-folder filter. Otherwise search by name and confirm the result sits under the right sub-folder.
3. Link the client's folder directly in `<Client>.md` (Context section) — not the shared parent folder, and not the alphabetical sub-folder. The direct client-folder link is what belongs in the vault.

Use this during client onboarding and intake when linking raw Drive context into
client notes.
