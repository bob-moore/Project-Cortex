# Audits

This directory holds durable audits of imported source material before it is
promoted into canonical roles, workflows, skills, tools, or policies.

Use these notes to record:

- what the imported material does well
- what conflicts with vault methodology
- what requires primary-source verification
- what should become canonical behavior
- what should remain legacy reference material

Audits are not active runtime behavior.
