# Resume Notes

Use this directory for compact, durable notes that let a future runtime resume
work without reconstructing the whole prior session.

These notes are different from `harness/session-logs/`, which stores runtime
transcript backups. A resume note is a curated handoff: current objective,
state, changed files, decisions, blockers, validation, and next action.

Create these notes through the `vault-stash-session` workflow when possible.
