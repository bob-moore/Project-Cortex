## Decisions

- Keep the canonical behavior in `.agents/`; `.claude/` remains a thin adapter layer.
- Use neutral CLI tools for evidence collection and preserve raw output beside normalized packets.
- Treat scores as directional. Do not present SiteOne's crawl-response performance result as equivalent to Lighthouse browser performance or field Core Web Vitals.
- Report security-header and TLS findings as observed configuration signals requiring hosting/CDN verification, not as proof of exploitability.
- Keep the sitemap 404 explicitly marked as a blocked specialist check until the canonical sitemap location is confirmed.
- Do not run production mutations, CMS changes, paid SEO APIs, or credentialed data sources in this phase.
- Linkinator was intentionally skipped on the live run because the current wrapper forces recursive crawling without the audit's explicit page cap; SiteOne already supplied broad broken-link evidence.
