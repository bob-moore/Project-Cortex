# Policies

Policy documents for agent behavior in this vault.

Core policies:

- [[contract]]: what agents may do alone, what queues for the user, and what
  wakes the user.
- [[approvals]]: blast-radius approval classes.
- [[done]]: definition of done and valid verification evidence.
- [[runtime-routing]]: runtime and role dispatch policy.
- [[budget]]: runtime and automation budget policy.

Expected additional topics include memory writes, verification, tool access, and
shared-work boundaries.
