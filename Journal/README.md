# Journal

Bob's personal daily notes live here.

Daily entries use `YYYY-MM-DD.md`. They are shared vault content, not
agent-operating memory. Agents may review entries when Bob asks, when a workflow
explicitly needs recent personal context, or during occasional vault review.

Do not use Journal entries as durable agent memory. Promote reusable operating
knowledge to [[harness/memory]] or the relevant [[harness]] note.

## Future

A tag or mention convention for inviting agent attention into a daily note is
deferred until Bob explicitly asks for it.
