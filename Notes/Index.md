# Notes

Standalone notes that don't fit under [[Projects/Index|Projects]] (client/project work), `harness/` (agent operating knowledge), `org/` (people and teams), `reviews/` (opt-in review material), or `reference/` (durable system/API knowledge). If an idea, observation, or piece of research doesn't belong to any of those, it goes here.

Every note in this folder should link back here and to at least one related note elsewhere in the vault. An unlinked note is a bug; see `harness/manual.md`.

## All Notes

- `meetings/` — standalone meeting-prep notes (attendees, purpose, calendar link, and context). Distinct from `inbox/`, which is the raw-transcript staging area the `vault-intake` workflow processes and clears.
- `1-1/` — 1:1 meeting notes, one file per person per date (`<Person> YYYY-MM-DD.md`), via `vault-capture-1on1`.
- `incidents/` — incident docs (main note + RCA + deep dive + drafts), via `vault-incident-capture`.
